Valexity Technologies is committed to ensuring that our website is accessible to people with disabilities. We strive to conform to the **Web Content Accessibility Guidelines (WCAG) 2.2, Level AA**, published by the World Wide Web Consortium (W3C).

## Conformance Status

We are actively working toward full WCAG 2.2 AA conformance. Current measures implemented include:

- Semantic HTML landmarks (header, main, footer, nav) for screen reader navigation.

- Keyboard-navigable interface with visible focus indicators on all interactive elements.

- A “Skip to main content” link at the top of every page.

- Descriptive alt text on informative images; decorative images are hidden from assistive technology.

- Accessible form labels linked to their input fields using htmlFor / id associations.

- Form error and status messages announced to screen readers via role="alert" and aria-live.

- Navigation menus marked with aria-label to distinguish primary navigation from footer navigation.

- Color contrast ratios meeting the WCAG 1.4.3 minimum (4.5:1 for normal text).

- A keyboard-accessible services menu that opens with Enter or Space and closes with Escape.

- Support for browser zoom up to 200% and the operating system “reduce motion” setting.

## Known Limitations

We are aware of the following areas that may not fully conform and are working to address them:

- Some older embedded PDF documents may not be fully accessible. Text equivalents are being added on a rolling basis.

## Technical Approach

This website is built with Next.js (React) and follows accessibility-first development practices. We use the WCAG 2.2 success criteria as our testing standard across the following conformance levels: Perceivable, Operable, Understandable, and Robust.

- Browser developer tools (Chrome Accessibility Tree, Lighthouse audits)

- Screen readers (NVDA on Windows, VoiceOver on macOS/iOS)

- Keyboard-only navigation testing
